## Demo example: Integrating Perfect-Live Web SDK into a React Native App

To integrate the Perfect-Live Web SDK into your React Native application, set the `url` value to the address of your demo stand, including the session token. Optionally, you can also provide localization and/or theme parameters.

### URL Example:

```https://demo.dev.perfect.live/sdk/page?session=<here_is_your_token>&theme=dark&locale=en_US```

### Optional Parameters:

- **theme**: `light` | `dark`
- **locale**: `ru_RU` | `en_US`

Both `theme` and `locale` are optional and can be omitted if not needed.
